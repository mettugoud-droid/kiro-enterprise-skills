# Workflow

1. Identify audience.
2. Extract key messages.
3. Organize into sections.
4. Recommend icons.
5. Suggest charts.
6. Define color palette.
7. Produce layout hierarchy.

## Output

- Title
- Subtitle
- Sections
- Icons
- Statistics
- Timeline
- Callouts
- Footer
