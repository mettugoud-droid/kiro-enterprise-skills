# Kiro Enterprise Skills

> A curated collection of production-ready Kiro Skills for AI Engineering, Software Development, Business Intelligence, Marketing, Cybersecurity, Automation, and E-commerce.

## Features

- Production-grade Skills
- Modular architecture
- Reusable prompts
- Enterprise coding standards
- MCP-ready
- Claude & GPT optimized
- Business Intelligence workflows
- Marketing automation
- Video generation
- Documentation templates

---

## Installation

Clone into your Kiro skills directory.

```bash
git clone https://github.com/mettugoud-droid/kiro-enterprise-skills.git
```

Copy the required skills into

```
~/.kiro/skills/
```

Restart Kiro.
